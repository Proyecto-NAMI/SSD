# NAMI - Spec Driven Development

Repositorio de planificación SDD del proyecto interdisciplinar NAMI, desarrollado por alumnado de 2.º DAM de Monlau.

## Contexto

NAMI nace para reducir una barrera concreta asociada a la soledad no deseada de las personas mayores: la dificultad para mantener una comunicación frecuente con familiares y personas de confianza mediante aplicaciones demasiado complejas.

La propuesta es una aplicación móvil privada, sencilla y accesible, con botones grandes, navegación clara, pocas opciones simultáneas y especial atención a los mensajes de voz. El diseño parte del proceso de Design Thinking realizado por el equipo y del prototipo de Figma.

## Objetivo del MVP

El MVP permitirá:

- crear y mantener un perfil;
- añadir contactos de confianza;
- consultar conversaciones uno a uno;
- enviar mensajes de texto;
- grabar, revisar, enviar y reproducir notas de voz;
- recibir confirmaciones claras de envío;
- ajustar el tamaño del texto y usar texto a voz.

Para mantener una entrega viable, quedan fuera del MVP las llamadas, videollamadas, fotografías, biometría, chats grupales y dinámicas automáticas.

## Estado

La planificación SDD está redactada. Antes de iniciar la implementación, el equipo debe confirmar las decisiones pendientes de `spec.md` y `plan.md`, especialmente la versión mínima de Android, el límite de audio, la búsqueda privada por teléfono y la política de conservación y borrado.

## Privacidad

Los documentos y evidencias usan datos ficticios. No deben añadirse credenciales, teléfonos reales, conversaciones privadas ni secretos al repositorio.
